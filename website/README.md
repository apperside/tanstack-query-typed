# tanstack-query-typed — website

Marketing site and interactive playground for
[`tanstack-query-typed`](https://www.npmjs.com/package/tanstack-query-typed).

Built with **Vite + React + TypeScript**, **Tailwind CSS v4**, **TanStack Router**
(file-based, route-level code-splitting), **Motion** for micro-animations, and
**ESLint + Prettier + Lefthook** for code quality. The site lives in this
sub-directory so it stays fully independent of the library package at the repo root.

## Commands

All commands run from `website/`:

```sh
npm install          # install dependencies (also installs the git pre-commit hook)
npm run dev          # start the Vite dev server (http://localhost:5173)
npm run build        # type-check + production build to dist/
npm run preview      # preview the production build (http://localhost:4173)
npm run typecheck    # tsc -b, no emit
npm run lint         # eslint (flat config)
npm run format       # prettier --write .
npm run format:check # prettier --check .
npm run hooks:install # (re)install the git pre-commit hook
```

## Project structure

```
website/
├─ index.html               # app entry + baseline SEO meta
├─ vite.config.ts           # Vite + router/react/tailwind plugins, base path, chunking
├─ eslint.config.js         # ESLint flat config (React + TS)
├─ lefthook.yml             # pre-commit: prettier --write + eslint --fix on staged files
├─ scripts/
│  └─ install-git-hooks.mjs # installs .git/hooks/pre-commit -> website lefthook
└─ src/
   ├─ main.tsx              # app bootstrap + router
   ├─ routeTree.gen.ts      # generated by the router plugin (do not edit)
   ├─ routes/               # file-based routes (__root, index, playground)
   ├─ components/           # reusable UI (Nav, Footer, Logo, …)
   ├─ sections/             # page sections (landing content)
   ├─ lib/                  # shared helpers + site metadata
   └─ styles/               # global CSS + design tokens (@theme)
```

## Design tokens

Dark, Linear/Vercel-inspired. Tokens are defined once in `src/styles/index.css`
under `@theme` and exposed as Tailwind utilities and CSS variables:

| Token                 | Utility examples                  |
| --------------------- | --------------------------------- |
| `--color-background`  | `bg-background`                   |
| `--color-card`        | `bg-card`                         |
| `--color-foreground`  | `text-foreground`                 |
| `--color-muted`       | `text-muted`                      |
| `--color-accent`      | `bg-accent` / `text-accent`       |
| `--color-accent-soft` | `bg-accent-soft`                  |
| `--font-sans`         | `font-sans` (Inter Variable)      |
| `--font-mono`         | `font-mono` (JetBrains Mono Var.) |

Fonts are self-hosted via `@fontsource-variable/*` (loaded in `main.tsx`) with
`font-display: swap`.

## Deploying to a sub-path

The base path is configurable, so the site can be served from a sub-path
(e.g. GitHub Pages). It defaults to `/`:

```sh
BASE_PATH=/tanstack-query-typed/ npm run build
```

Both Vite (`base`) and the router (`basepath: import.meta.env.BASE_URL`) read it.

## Git hooks

`npm install` runs `prepare`, which installs a `.git/hooks/pre-commit` hook (at the
repo root) that runs this directory's `lefthook.yml`: Prettier and ESLint `--fix`
over staged files, scoped to `website/`. Re-run manually with `npm run hooks:install`.
